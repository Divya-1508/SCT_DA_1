#  Superstore Sales Analytics Dashboard

An interactive Excel dashboard built to analyze sales performance, customer activity, regional trends, and product category performance using the Superstore dataset.

---

##  Project Overview

This project transforms raw sales data into actionable business insights through interactive visualizations and KPI tracking.

The dashboard enables users to:

- Monitor overall business performance
- Analyze sales trends over time
- Compare category-wise sales performance
- Evaluate regional sales distribution
- Interact with data using dynamic slicers

---

##  Business Problem

Businesses generate large volumes of sales data but often struggle to extract meaningful insights quickly.

This dashboard addresses that challenge by providing a centralized view of key performance indicators and sales trends, enabling data-driven decision-making.

---

##  Dashboard Features

### KPI Cards
- Total Sales
- Total Orders
- Total Customers
- Average Sales per Order

### Interactive Visualizations
- Sales by Category
- Monthly Sales Trend
- Sales by Region

### Dynamic Filtering
- Region-based slicer for interactive analysis

##  Key Insights

### Category Performance
- Technology generated the highest sales revenue.
- Office Supplies contributed consistent sales volume.
- Furniture showed moderate performance compared to Technology.

### Monthly Trends
- Sales exhibited noticeable growth during the final quarter.
- Peak sales were observed in November and December.

### Regional Analysis
- The West region contributed the highest revenue share.
- Regional performance varied significantly across the dataset.
